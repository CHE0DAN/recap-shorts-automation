# 기본 효과음 꾸러미

설정 화면에서 효과음 폴더를 고르지 않으면 여기서 고릅니다(`config/fx.json` 의 `sfx.libraries`). 폴더마다 `manifest.json` 에 소리마다 종류·길이·원본 파일 이름·이용 조건을 적었습니다. 이 폴더의 소리는 저장소의 MIT 라이선스를 따르지 않습니다.

## chime/ — CC BY 4.0

| 파일 | 원본 |

효과음: OtoLogic (https://otologic.jp), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja). 영상에 쓰면 출처 표기가 필요합니다. 앱은 이 소리가 들어간 영상의 설명 문구에 표기를 자동으로 넣습니다(`manifest.json` 의 `credit`).

## user_meme/ — 원 출처 미상

인터넷에 도는 밈 효과음 16개입니다. 원 출처와 이용 조건을 확인하지 못했습니다. 권리자가 분명한 소리(게임·상표·노래·특정 영상에서 잘라 낸 것)와 영상·시스템 소리에서 가져온 것으로 보이는 소리(`config/sfx_rights.json` 의 high·medium)는 넣지 않았습니다.

- 이 폴더에는 라이선스가 없습니다. 여기 있다고 해서 재사용을 허락한다는 뜻이 아닙니다.
- 남은 소리도 안전하다는 보증은 없습니다. 영상에 쓸 때의 책임은 쓰는 사람에게 있습니다.
- 원본 파일 이름만 보고 매긴 위험도는 `config/sfx_rights.json` 에 있습니다. 검수 화면이 영상에 들어간 '주의' 소리를 알려 줍니다(막지는 않음).
- 쓰고 싶지 않으면 설정 화면에서 내 효과음 폴더를 고르세요.

권리자이고 빼기를 원하면 저장소 이슈로 알려 주세요.
